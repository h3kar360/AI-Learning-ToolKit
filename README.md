# AI Learning ToolKit

This is an AI powered learning helper. With this, you can upload a PDF and ask our AI any questions regarding your uploaded PDF or you can generate automated flash cards with a press of a button.

## How do I run this code?

First you can clone this repository. Afterwards you can run the following commands.

```
npm install
npm run dev
```

Now you are all set.
